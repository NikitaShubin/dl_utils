# utils: ноутбуки, тайминг и повторные попытки

Контексты для замеров и подписей в Jupyter, звуковое уведомление, отложенная
инициализация и декоратор `Retry`.

## Замерить время

```python
from utils import TimeIt

with TimeIt('загрузку модели') as timer:
    model = load_model()

print(timer())  # время в секундах
```

Если заголовок не нужен, создавайте `TimeIt()` без аргумента — контекст всё
равно сохранит время в `timer.time_spent`.

## Подписать начало и конец

```python
from utils import AnnotateIt

with AnnotateIt('Обработка кадров...', 'Кадры обработаны.'):
    process_frames()
```

`AnnotateIt` печатает первую строку перед блоком и заменяет её второй после
завершения — удобно в долгих ноутбуках.

## Звук по завершении

```python
from utils import Beep

with Beep(60, 300):
    train_model()
```

Аргументы — пороги в секундах: если операция шла меньше 60 секунд, звука не
будет; от 60 до 300 — один гудок; больше 300 — два. Требуется пакет
`jupyter_beeper`; вне Jupyter контекст просто ничего не делает.

## Отложенная инициализация

```python
from utils import DelayedInit

model = DelayedInit(MyModel, kwargs={'device': 'cuda'})
# Экземпляр MyModel ещё не создан.

result = model.predict(frame)  # создаётся здесь, при первом обращении
```

`DelayedInit` принимает класс и аргументы его конструктора. Дополнительно можно
передать `args_func` и `kwargs_func` — функции, которые вычислят аргументы в
момент инициализации.

## Повторить операцию при ошибке

```python
from utils import Retry

@Retry(max_attempts=5, exception=ConnectionError, sleep_s=1, backoff=2)
def download(url):
    ...
```

`exception` может быть типом, экземпляром исключения, строкой с текстом ошибки
или коллекцией таких значений. `sleep_s` задаёт паузу между попытками,
`backoff` — множитель её роста (не более 5 секунд).

## Ограничения

- `TimeIt` использует `time.time()`, а не монотонные часы; для точных
  бенчмарков лучше `time.perf_counter()`.
- `Beep` работает только в Jupyter и только при установленном
  `jupyter_beeper`.
- `DelayedInit` подменяет класс экземпляра при первом обращении; не
  используйте его для объектов, которые проверяются через `isinstance` до
  инициализации.
- `Retry` повторяет только те исключения, которые перечислены в `exception`;
  остальные пробрасываются сразу.
