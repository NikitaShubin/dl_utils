# keras_utils: данные

`SegDataLoader` — `keras.utils.Sequence` для сегментационных датасетов с
папками `inp` и `out`.

## Структура датасета

```text
dataset/train/
    inp/
        00000001.png
        00000002.png
    out/
        00000001.png
        00000002.png
```

Файлы в `inp` и `out` сортируются по имени и сопоставляются по позиции.
Загрузчик проверяет, что имена без расширения совпадают (регистр не важен),
но расширения могут различаться. Число файлов не проверяется: лишний файл
сдвигает пары и вызывает `assert`, а лишний файл в `inp` в конце списка
приводит к `IndexError`; замыкающий лишний файл в `out` может остаться
незамеченным. Нумерация с ведущими нулями (`00000001.png`) сохраняет числовой
порядок при лексикографической сортировке.

## Загрузить датасет

```python
from keras_utils import SegDataLoader

train_loader = SegDataLoader(
    'dataset/train',
    num_classes=4,
    batch_size=8,
    shuffle=True,
)

model.fit(train_loader, epochs=20)
```

`num_classes` — число каналов one-hot, включая фон. Маска читается как
одноканальная и должна содержать целые индексы `0..num_classes-1`; значение
`0` обычно означает фон. Если в маске есть значение больше
`num_classes-1`, `keras.utils.to_categorical` выбросит `IndexError`.

Например, если четыре класса включают фон, маска содержит `0..3`, а
`num_classes=4`. Если четыре класса — это объекты, а фон идёт отдельно, маска
содержит `0..4`, и нужно `num_classes=5`.

Максимум нужно смотреть по всему датасету или по спецификации классов, а не по
одной маске: редкий класс может отсутствовать в конкретном файле.

```python
from pathlib import Path

import cv2

out_dir = Path('dataset/train/out')
max_label = max(
    cv2.imread(str(mask_file), cv2.IMREAD_GRAYSCALE).max()
    for mask_file in out_dir.glob('*.png')
)
num_classes = int(max_label) + 1
```

Изображение читается как BGR, переводится в RGB и масштабируется в `[0, 1]`
до аугментации. Без `num_classes` маска остаётся одноканальной и делится на
255, поэтому бинарная маска должна храниться как `0/255`. Если у вас маска
`0/1`, приведите её к `0/255` или используйте `num_classes=2` и one-hot.

## Выбрать лосс

- `num_classes` задан → one-hot маска → `categorical_crossentropy`;
- `num_classes` не задан → маска `0/255` после деления на 255 → `binary_crossentropy`.

Для двух классов (фон и объект) проще бинарный режим: не задавайте
`num_classes`, используйте маску `0/255` и модель с `out_filters=1`.

`sparse_categorical_crossentropy` для этого загрузчика не подходит: он не
отдаёт целочисленные индексы классов. Модель и её выход описаны в разделе
[«Модели»](models.md), метрики и колбеки — в [«Обучение»](training.md).

## Аугментация

```python
import albumentations as A

from keras_utils import SegDataLoader

transforms = A.Compose([
    A.HorizontalFlip(p=0.5),
    A.RandomCrop(512, 512),
])

loader = SegDataLoader(
    'dataset/train',
    num_classes=4,
    transforms=transforms,
    batch_size=8,
)
```

Преобразователь вызывается как `transforms(image=inp, mask=out)` и должен
вернуть объект с методом `.values()`, где первые два значения — изображение и
маска. Так работает `A.Compose`. Геометрические операции применяются к маске
синхронно с изображением. `inp` уже имеет тип `float32` и диапазон `[0, 1]`,
`out` остаётся `uint8`; one-hot выполняется после преобразований.

`AlbTransforms` как объект подходит: его `__call__` возвращает словарь. А вот
метод `AlbTransforms.image_mask_func()` возвращает кортеж и напрямую в
`transforms` не подходит — используйте `A.Compose`, сам `AlbTransforms` или
обёртку, которая возвращает словарь с ключами `image` и `mask`.

## Чем отличается от tf_utils

[`tf_utils.get_datasets`](../tf_utils.md) читает те же папки, но всегда делает
one-hot по `num_classes`, ресайзит маску `nearest` и не поддерживает бинарный
режим. Для `UNet(out_filters=1)` остаётся `SegDataLoader`; для многоклассовой
сегментации подойдёт любой из двух конвейеров.

## Увеличить эпоху

```python
loader = SegDataLoader(
    'dataset/train',
    num_classes=4,
    batch_size=8,
    epoch_multiplier=3,
)
```

Каждая эпоха повторяет семплы три раза в перемешанном порядке. Полезно для
маленьких датасетов.

## Проверить батч

```python
loader.show()
```

Метод берёт случайный батч и рисует пары «изображение — маска» через
`matplotlib`.

## Ограничения

- Папки `inp` и `out` обязательны; при их отсутствии будет `FileNotFoundError`.
- Файлы сопоставляются по порядку сортировки; имена без расширения должны
  совпадать. Лишний файл сдвигает пары (`assert`) или даёт `IndexError`, если
  он в `inp` в конце списка.
- Маска читается как одноканальная. Цветная маска потеряет каналы.
- Значения маски должны укладываться в `0..num_classes-1`; `255` в
  многоклассовом режиме приведёт к `IndexError`.
- В бинарном режиме маска делится на 255, поэтому в файлах должны лежать
  `0` и `255`, а не `0` и `1`.
- `transforms` должен возвращать объект с методом `.values()`, причём
  изображение должно идти первым, а маска — второй.
- Загрузчик не меняет размер изображений: это должна делать аугментация.
- При `drop_incomplete_batch=False` последний батч может быть короче
  `batch_size`; для `BatchNormalization` это иногда нежелательно.
- Параметр называется `use_multitherading` (опечатка сохранена в API).
