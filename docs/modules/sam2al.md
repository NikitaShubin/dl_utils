# 🎬 sam2al.py — SAM 2 для видео

Интерактивная и автоматическая сегментация видео: подсказки на опорных кадрах,
распространение масок по треку и выгрузка результата в CVAT.

**Зависимости:** `sam2`, `torch`, `numpy`, `opencv-python`, `pandas`, `tqdm`,
`modelscope` (для скачивания); файлы [`cvat.py`](cvat/README.md),
[`seg.py`](seg.md), [`pt_utils.py`](pt_utils.md),
[`video_utils.py`](video_utils.md), [`ml_utils.py`](ml_utils.md),
[`utils.py`](utils/README.md).

## ⚙️ Установить модель

В Docker-образах `dl_utils` и `PreAnnotation` пакет `sam2`, декодер `decord` и
веса уже установлены. Вне Docker:

```bash
pip install sam2 decord modelscope
```

`modelscope` нужен только для автоматической загрузки весов. Без него
подготовьте файл модели заранее.

```python
from sam2al import SAM2

# Имя файла: ищется в ~/models, при отсутствии скачивается через ModelScope:
sam2 = SAM2(model_path='sam2.1_hiera_large.pt', half=False)

# Готовый файл в другом месте:
sam2 = SAM2(model_path='/data/models/sam2.1_hiera_large.pt')
```

Поддерживаются `sam2.1_hiera_tiny.pt`, `small`, `base_plus` и `large`.
`config='auto'` подбирает YAML по имени модели, `device='auto'` — доступное
устройство. Для файла с другим именем укажите `config` явно. `half=True`
включает `bfloat16` и ускоряет работу на подходящей GPU.

## 📥 Загрузить видео

```python
from sam2al import SAM2

sam2 = SAM2(half=False)
sam2.load_video(
    'data/video.mp4',
    prompts_file='prompts/Project 1.tsv',
    offload_video_to_cpu=True,
)
```

Если `prompts_file` не указан, файл подсказок создаётся рядом с видео с тем же
именем и расширением `.tsv`. Если передать существующую папку, имя файла
соберётся из имени видео. Родительскую папку для TSV создайте заранее:
`df_save` не создаёт её сам. Подсказки сохраняются автоматически, поэтому
разметку можно прервать и продолжить.

## 💡 Поставить подсказки

```python
# Новый объект в середине видео:
sam2.go_to(frame=120, obj_id='new', label='car')

# Маска-подсказка, рамка и точки включения/исключения:
sam2.points2masks(
    msk_points=[],
    box_points=[[100, 200, 300, 400]],
    pos_points=[[150, 250]],
    neg_points=[],
)
```

`points2masks` вызывается из [`IPYInteractiveSegmentation`](ipy_utils.md) при
кликах. Вручную её удобнее использовать для сценариев без виджета. Форматы:

- `msk_points` — контур `[[x, y], ...]`, который заливается в маску;
- `box_points` — один прямоугольник `[[x0, y0, x1, y1]]`;
- `pos_points`, `neg_points` — списки точек `[[x, y], ...]` включения и
  исключения.

Пустой список означает, что подсказка этого типа не используется. Координаты —
в пикселях исходного кадра.

## 🧭 Перейти к объекту

```python
sam2.go_to(frame=0, obj_id=0)       # конкретный объект
sam2.go_to(obj_id='last')           # последний созданный
sam2.set_label('person')            # сменить метку текущего объекта
```

`obj_id` — номер трека, а не индекс в датафрейме.

## 🧱 Собрать разметку

```python
df, file, true_frames = sam2.build_subtask(fit_segments=True)
```

`fit_segments=True` подгоняет контуры соседних объектов встык и убирает
наложения; используется [`fit_segments_in_df`](seg.md). Результат кешируется
только в этом режиме: ключ — хеш подсказок. Если подсказки, метки или группы
не менялись, повторный вызов не запускает трекинг. `fit_segments=False` кеш не
использует и собирает контуры без подгонки.

`export2cvat` вызывает `build_subtask` сам, поэтому отдельный вызов нужен,
только если вы хотите проверить или сохранить датафрейм до экспорта.

Возвращается подзадача в формате CVAT `(df, file, true_frames)`: датафрейм
разметки, путь к видео и словарь соответствия кадров. Формат описан в
[cvat: датафрейм](cvat/dataframes.md).

## 📤 Выгрузить в CVAT

```python
from cvat_srv import CVATSRV

srv = CVATSRV(host='http://localhost:8080', username='admin', password='admin')

# Проект должен существовать; создаём его при первом запуске:
if 'Project 1' not in srv:
    srv.new('Project 1', labels=['person', 'car'])
project = srv['Project 1']

url = sam2.export2cvat(project, fit_segments=True)
print(url)
```

`export2cvat` не создаёт проект и не добавляет в него метки. Проект должен уже
содержать все метки, которые встречаются в подсказках; иначе CVAT отклонит
создание задачи. Строковые метки создаются с типом `any`, который принимает
полигоны; если проект использует ограниченный тип, разрешите `polygon`
([метки](cvat/labels.md)).

Имя задачи строится как `<имя проекта>_<имя видео без расширения>`. Для
проекта `Project 1` и видео `people.mp4` получится `Project 1_people`. Если
задача с таким именем уже есть, её разметка заменяется целиком; если нет —
создаётся новая задача с подмножеством `Train`. Метод возвращает URL первого
job; у задачи может быть несколько job, остальные доступны через
`task.values()`.

Если нужно добавить разметку к существующей задаче, а не заменить её,
сложите старый и новый датафреймы через `concat_dfs(..., smart=True)` и
отправьте XML через `task.set_annotations` — так поступает
`Segmentation.ipynb`. Серверные объекты описаны в [cvat_srv](cvat_srv/README.md),
готовый сценарий — в [предразметке](../preannotation.md).

## 💾 Сохранить XML

```python
sam2.save2cvat_xml('results/annotation.xml', fit_segments=True)
```

XML можно импортировать в CVAT как разметку задачи через
`task.set_annotations`; формат описан в [бекапах](cvat/backups.md). В отличие
от `export2cvat`, этот способ не создаёт задачу и не загружает видео.

## ⚠️ Ограничения

- Модель скачивается в `~/models` через ModelScope. Без `modelscope` и без
  готового файла загрузка невозможна; для имени вне списка поддерживаемых
  моделей нужен явный `config`.
- `half=True` ускоряет работу на современных GPU, но требует поддержки
  `bfloat16`; на старых картах возможны ошибки.
- Подсказки хранятся в TSV и привязаны к длине видео. При замене видео файл
  подсказок нужно удалить или указать новый; родительская папка TSV должна
  существовать.
- Один объект должен иметь один `obj_id`; разные объекты с одинаковым номером
  смешаются в один трек.
- `export2cvat` заменяет разметку одноимённой задачи целиком, а не добавляет
  новые объекты к старым.
- `build_subtask` держит все кадры видео в памяти или на CPU в зависимости от
  `offload_video_to_cpu`; длинные видео требуют много RAM или диска.
- Сервер CVAT не входит в репозиторий: адрес и учётные данные нужно получить
  у администратора, а проект и метки создать заранее.
