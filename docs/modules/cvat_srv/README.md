# cvat_srv.py — работа с CVAT-сервером

Обёртка над официальным CVAT SDK: навигация по проектам, задачам и подзадачам,
бекапы, экспорт и импорт разметки, а также локальное редактирование копий
разметки с отправкой обратно.

**Зависимости:** `cvat.py`, `utils.py`, `video_utils.py`, `cvat_sdk`,
`pandas`, `numpy`, `Pillow`, `urllib3`, `tqdm`.

## Быстрый старт

Подключиться к серверу и открыть задачу по её настоящему имени в CVAT:

```python
from cvat_srv import CVATSRV

srv = CVATSRV(
    host='http://localhost:8080',
    username='admin',
    password='admin',
)

task = srv['Project 1']['Task 1']
print(task.url)
```

Экземпляр `CVATSRV` ведёт себя как словарь: `srv['Project 1']` — проект,
`project['Task 1']` — задача. Ключи — реальные имена объектов на сервере, а не
произвольные метки в коде.

## Два уровня работы

Модуль даёт два способа работать с данными:

| Уровень | Классы | Когда нужен |
| :--- | :--- | :--- |
| Серверные объекты | `CVATSRV*` | Навигация, бекапы, экспорт |
| Локальные копии | `CVATProject`, `CVATTask` | Правка в pandas |

Серверные объекты не хранят разметку: они ссылаются на неё и выполняют
операции на сервере. Локальная копия скачивает бекап, распаковывает его и
позволяет менять `df` и `file` в памяти.

- [Серверные объекты](remote.md) — подключение, навигация, создание, бекапы,
  аннотации, `ReadTasks`
- [Локальные копии](local.md) — `clone()`, правка задач и проектов, `push()`

## Общий сценарий

1. Подключиться к серверу: `CVATSRV(...)`.
2. Найти проект и задачу по именам: `srv['Project 1']['Task 1']`.
3. Если разметка уже готова — скачать её или бекап.
4. Если разметку надо менять — сделать локальную копию через `clone()`.
5. Изменить `df` и/или файлы, затем вызвать `push()`.

## Как устроено

`CVATSRVBase` задаёт древовидную навигацию: сервер → проект → задача →
подзадача. Каждый уровень знает своего предка и потомков, а `__getitem__`
ищет объект по имени или номеру.

Локальные классы `CVATProject`, `CVATTask`, `CVATJob` наследуются от
`_CVATBase`. Они скачивают бекап, распаковывают его во временную папку, парсят
`annotations.json` в `pandas.DataFrame` и при `push()` собирают архив обратно.
Временные пути хранятся в `paths2remove` и удаляются при разрушении объекта или
явном вызове `rm_all_paths2remove()`.

## Ограничения

- Для локального редактирования поддерживаются проекты и задачи; подзадачи
  редактируются в составе задачи.
- `CVATSRV` создаёт клиент при инициализации и делает сетевые запросы в
  конструкторе; без доступного сервера объект не создастся.
- Имена проектов и задач должны быть уникальными в пределах родителя:
  `__getitem__` падает, если найдено несколько совпадений.
- Бекапы и распаковка занимают место на диске; для больших проектов
  используйте `parted=True` и следите за свободным местом.
