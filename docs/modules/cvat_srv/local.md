# 💻 cvat_srv: локальные копии

`clone()` скачивает бекап и отдаёт объект, у которого разметка лежит в
`pandas.DataFrame`. Меняйте `df` и `file`, затем вызывайте `push()`.

## ✏️ Изменить разметку задачи

```python
task = srv['Project 1']['Task 1']

# Скачиваем задачу и распаковываем бекап во временную папку:
local_task = task.clone()

# В задаче может быть несколько подзадач; правим каждую:
for job in local_task.data:
    job.df = job.df[job.df['label'] != 'person']

# Собираем архив и отправляем обратно на сервер:
updated_task = local_task.push()
print(updated_task.url)
```

`push()` заменяет задачу на сервере: старая удаляется, новая создаётся из
локальной копии. Возвращается уже новый серверный объект; старый `task`
после этого устарел.

## 📦 Что лежит внутри задачи

```python
local_task = srv['Project 1']['Task 1'].clone()

print(local_task.info['name'])      # имя задачи
print(local_task.info['labels'])    # CVATLabels
print(len(local_task.data))         # число подзадач

job = local_task.data[0]
print(job.file)                     # видео или список изображений
print(len(job))                     # число кадров
print(job.df.columns)               # схема разметки
```

`job.df` — таблица аннотаций: `label`, `frame`, `type`, `points`, `outside`,
`attributes` и другие столбцы. `job.true_frames` сопоставляет номера кадров
исходного файла и прореженной последовательности. У неразмеченной задачи
`df` может быть `None`.

## ✏️ Изменить проект

```python
project = srv['Project 1']
local_project = project.clone()

# Перебираем задачи проекта и их подзадачи:
for local_task in local_project.data:
    for job in local_task.data:
        job.df = job.df[job.df['label'] != 'person']

updated_project = local_project.push()
```

По умолчанию проект отправляется по частям (`parted=True`): задачи
восстанавливаются в существующем проекте, старые версии удаляются. Для
небольших проектов можно отключить разбиение:

```python
local_project = project.clone(parted=False)
```

## ↔️ Переставить кадры

Если задача собрана из отдельных изображений, порядок можно задать по номерам
в именах файлов:

```python
local_task = srv['Project 1']['Task 1'].clone()
local_task.reorder_frames()
local_task.push()
```

Явный порядок передаётся списком индексов:

```python
local_task.reorder_frames([2, 0, 1])
```

Метод работает только для задачи с одной подзадачей и несколькими файлами
изображений. Для видео он не нужен.

## 💾 Сохранить изменения только локально

```python
local_task.push(local_only=True)
```

В этом случае архив и файлы разметки обновляются в распакованной папке, но на
сервер ничего не отправляется. Полезно, чтобы забрать данные и обработать их
другими инструментами.

## 🗑️ Убрать временные файлы

```python
local_task.rm_all_paths2remove()
```

Локальная копия занимает место на диске: архив и распакованная папка лежат во
временной директории. Они удаляются автоматически при уничтожении объекта, но
в долгом ноутбуке лучше освобождать их явно.

## ⚠️ Ограничения

- `clone()` можно вызывать только для проекта или задачи; подзадача
  редактируется в составе задачи.
- Изменения в `df` не проверяются на соответствие меткам проекта: перед
  `push()` убедитесь, что используемые `label` объявлены в `info['labels']`.
- `push()` пересоздаёт объект на сервере. Ссылки на старый объект и его `id`
  после отправки недействительны.
- Временные папки удаляются деструктором; если процесс упал, их придётся
  удалить вручную.
